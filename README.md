# 💜 Para Você — Site dedicado

Um site minimalista, moderno e emocional desenvolvido como uma homenagem pessoal. O design combina uma paleta escura com toques sutis de roxo e rosa, animações fluidas no scroll e um coração formado dinamicamente por imagens.

## ✨ Funcionalidades

- **Design limpo e contemporâneo** — fundo escuro, tipografia leve e espaçamento equilibrado.
- **Revelação suave no scroll** — cada elemento da página aparece com animações progressivas ao rolar a tela.
- **Galeria de imagens interativa** — clique em qualquer foto para visualizá-la em tamanho maior.
- **Coração dinâmico com imagens** — as mesmas fotos da galeria formam um coração visual com animação individual.
- **Responsivo** — adapta-se perfeitamente a dispositivos móveis, tablets e desktops.
- **Botão "voltar ao topo"** — facilita a navegação em telas longas.

## 🛠️ Tecnologias utilizadas

- HTML5 semântico
- CSS3 com variáveis, flexbox, grid e backdrop-filter
- JavaScript (ES6+)
- [GSAP](https://greensock.com/gsap/) — animações profissionais
- [ScrollTrigger](https://greensock.com/scrolltrigger/) — animações baseadas no scroll
- Google Fonts (Inter)
